01 / Foundation

AI Agent 是什麼？

AI Agent 讓 LLM 從單次文字生成，進一步成為能記住資訊、規劃任務並對環境採取行動的系統。

Wang et al. (2024) 的四模組整理

  • Profile：定義角色、個性與任務定位。
  • Memory：保存環境資訊與過去經驗。
  • Planning：把複雜目標拆成可執行的子任務。
  • Action：把高階決策轉成實際行動或工具呼叫。

11 / Takeaways

Key Takeaways

AI Agent 的價值來自把 LLM 放進一個能取得資訊、規劃任務、採取行動並接收回饋的系統。

1. Agent = LLM + System

Memory、Planning、Action 與 Feedback 讓模型可以處理持續性的多步驟任務。

2. 元件各有任務

Tool Use 連接外部能力；RAG 取得外部知識；Planning 拆解長程目標；Reflection 利用失敗經驗修正。

3. 遊戲需要責任邊界

Project E.X.I.T. 將任務、知識與高階輸出交給 Agent；移動、碰撞、HP、掉落與背包容量保留給 deterministic game rules。
